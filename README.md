# DataCamp Practical Exam | Modeling House Prices
Contains files used for the final project/practical exam for my DataCamp Data Scientist Associate in R certification.
DataCamp is a paid online learning platform offering courses and certifications in programming and statistics.
Certification was completed on January 2nd, 2026.

The project consisted of 5 Tasks, all of which needed to be passed and were graded by an auto-grader. The overall goal of the project was to create a model to predict the sale price of a house, using housing data gathered by a fictional real estate firm.

The Tasks:
  1. Load the dataset and calculate the number of missing values in a specific column.
  2. Clean all columns of data based on a list of specifications for each variable.
  3. Create new variables calculating a. average sale price grouped by number of bedrooms and b. the variance of that average.
  4. Train a baseline model to predict the sale price of a house, test it on a testing dataset.
  5. Train a comparison model to predict the sale price of a house, test it on a testing dataset.

This project was written in R. The final code for the project was written by me in DataCamp's DataLab Notebook interface. Helper functions for data cleaning were written by me using RStudio Ver. 2025.09.2+418.

To run this code for yourself:
  1. Download the R Markdown or R script file, house_sales.csv, validation.csv, and train.csv files in this repo.
  2. Run the R Markdown or R script file in RStudio or another R IDE. The filepath for loading files is already set to "Downloads."
  3. You may need to install the "tidyverse" and "randomForest" following packages before use. To do this, open R Studio and type the following lines of code: `install.packages("tidyverse")` and `install.packages("randomForest")`.
